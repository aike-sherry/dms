> 版本：演示版 v1.0（2026-07-20）
> 系统为纯前端演示，所有数据保存在浏览器 localStorage，无需后端。

## 二、全局功能（双端通用）

### 1. 顶部项目选择器
页面右上角的项目下拉（全部项目 / ON101 / ON102 / ON103）可全局筛选：
- 选「全部项目」：显示所有项目数据
- 选具体项目：首页统计卡、STUDY/SITE TMF、TRANSFER、REVIEW、SUBMISSION 全部联动过滤

### 2. 外观自定义
右上角「设置 → 外观背景」：
- 页面背景：8 个预设色板 + 自定义取色器
- 导航栏背景：8 个预设渐变 + 自定义颜色（自动生成渐变）
- 选择实时生效并持久保存，双端独立生效

### 3. 我的收藏（FAVORITE）
- 任意文件列表中，点击文件行右侧的星标 ☆ 即可收藏（仅具体文件可收藏，文件夹不可）
- 再次点击星标 → 提示「已取消收藏」
- FAVORITE 页面汇总所有已收藏文件，可直接下载

### 4. 界面布局
- 顶部为白色通栏：左侧 LOGO +「研究文件管理系统」，右侧项目选择器、用户区、设置/通知图标
- 左侧导航为**悬浮圆角卡片**：蓝色渐变卡片悬浮于浅灰页面背景之上，四周留白（与顶栏之间有明显灰色空隙，上/左/下对称），卡片四角圆角；导航背景渐变可在「外观背景」中自定义
- 右侧为内容区，各页标题（如 HOME）显示在内容区顶部

### 5. 表格列版式（全系统统一，长期设计规范：标题居中、字段居中、间距协调）
- 所有表格**表头与字段内容一律水平居中**，含名称列——图标 + 名称作为整体居中显示，超长名称省略号截断、悬浮可见全文；表格内编辑态输入框（行内重命名、新建行录入）同样居中
- 行高与间距全系统统一（表头 px-4 py-3、单元格 px-4 py-4），不再有任何左对齐/缩进特例；所有主列表表格统一固定布局：名称列约 18%~26% 占比，日期/人员/编号/大小/操作等元数据列按内容定宽；SUBMISSION 递交概况矩阵因列数多保持自适应布局（唯一例外）
- 实现集中于共享组件 `common.tsx`（DataTable/Th/Td/Tr/NameTh/NameTd），新页面/新表一律复用，禁止局部样式特例

## 三、管理人员（PM）操作指南

### 1. 首页（HOME）
- STUDY TMF 环形图：全项目归档率；SITE TMF 四张状态卡（上传/待审核/驳回/归档，含较上月环比）。口径：所有统计只数具体文件，Excel 导入生成的空文件夹不计入
- 统计汇总柱状图：按月查看各状态文件量（同样只统计具体文件）
- STUDY TMF / SITE TMF 列表：含「项目经理」「临床监查员」列
- **研究中心管理**（R32 起，替代原「CRA 分配」）：研究中心注册表是全系统唯一的中心数据源（SITE 目录创建勾选列表、双端递交矩阵中心列、CRA 上传弹窗中心下拉、各页「临床监查员」列均实时读取此处）：
  - 右上角「新增中心」→ 弹窗填写项目编号（已有编号可 datalist 点选）+ 研究中心名称 + CRA（下拉取自后台「账户配置」中的执行人员账号，可暂不分配）；同项目下同一名称重复添加会被提示拦截
  - 行内「编辑」：可改名称与 CRA；**已建目录的中心项目编号锁定不可改**，改名会级联同步已建 SITE 目录名称、文件归属与递交矩阵（已录入的递交日期保留）
  - 行内「删除」：未建目录的中心直接删除；**已建目录的中心会弹确认提示**（仅移除注册表配置，已建目录与文件保留，但目录创建/递交矩阵/上传弹窗等处不再显示该中心）
  - 各页面的「临床监查员」列实时同步；中心未分配 CRA 时显示「—」
- **PM 分配**：为每个项目分配/更换项目经理

### 2. TRANSFER（文件上传与归档）
PM 专属上传通道：
1. 点工具栏「上传」下拉 → 选「上传文件」或「上传文件夹」：弹窗打开后自动弹出系统文件/文件夹选择框（**未选项目编号时先提示选项目**，选好后再点一次即可）；弹窗内也保留「上传文件 / 上传文件夹」双卡片与拖拽区
2. **必须选择项目编号**（下拉取自 STUDY TMF 目录，即归档目标）；PM 项目级上传**无「研究中心」字段**（弹窗不显示、落库 center 为空，命名模板中的中心占位符自动省略）
3. **目标文件夹级联（可选）**：选好项目并选文件后，弹窗出现「目标文件夹」级联选择——一级下拉列出该项目 STUDY TMF 目录下的一级文件夹，所选一级有子文件夹时再出二级下拉；选中后提示「归档时将直通该文件夹」，归档时文件（上传文件夹时整个文件夹连同子文件一起，不拆散）直接落入该文件夹，跳过路由表；项目暂未创建目录时显示琥珀色提示「该项目暂未创建目录」，不选目标文件夹则仍按「归档规则」路由（未识别的进 99 待分拣）
4. 上传后文件出现在列表（**上传即自动命名**：命中词典按「命名规则」模板渲染规范名，未识别保留原名并提示将进 99 待分拣；PM 上传直接套用模板，无需确认步骤），状态为「归档」
5. **页面级拖拽（R34 起）**：把本地文件或整个文件夹直接拖到「文件上传」列表区松手 → 上传弹窗自动打开并进入**暂存确认流**——「待上传（N 个文件）」区块列出全部待传文件（拖入文件夹时保留文件夹结构、注明文件夹名），选好项目编号后点底部「确认上传（N）」一次性按命名规则自动命名落库；文件夹拖入会建同名文件夹条目、子文件挂为其子级
6. 列表保留「智能命名 / 智能纠错」入口，手动改名后仍可重新规范化
7. 点击「归档」→ 按「归档规则」自动路由：识别文档类型后归入对应项目 STUDY TMF 的「分区 / 文档类型」文件夹（分区/类型文件夹不存在时自动创建，STUDY TMF 页可逐级钻取查看）；未识别或无路由的文件进入「99 待分拣」（警告提示，需人工分拣）；上传时已选目标文件夹的文件/文件夹直接直通该文件夹
- 「归档规则」：工具栏按钮打开路由配置弹窗（文档类型 → 8 个 TMF 分区：01 试验管理文件 / 02 伦理与监管文件 / 03 研究者与中心文件 / 04 受试者文件 / 05 试验用药文件 / 06 数据管理与统计 / 07 监查与安全性 / 99 待分拣），默认路由可改可删，底部可新增（标准类型下拉 + 自定义输入）
- 「命名规则」：工具栏按钮（「归档规则」旁）打开命名模板配置弹窗——模板输入框 + 占位符胶囊（项目编号/文档类型/版本/日期/研究中心，点击在光标处插入）+ 示例值实时预览 + 恢复默认；默认模板 `{项目编号}-{文档类型}-V{版本}（{日期}）`；保存后 PM 上传自动命名与 CRA 上传确认命名均按此模板生成规范文件名
- 「待分拣」：工具栏按钮（带琥珀色数量徽标）打开 99 待分拣队列——归档时未识别文档类型或无匹配路由的文件在此暂存；每行选择目标分区（默认按路由表推荐）点「归位」，文件即移入 STUDY TMF 对应分区，全部归位完徽标自动清零
- **版本链（同文档新版本自动递增并关联历史版本）**：上传文件识别出的文档类型与库内历史文件相同（同项目同中心，不含文件夹与已驳回）时，版本号自动取「文件名解析版」与「历史最大版 +1」的较新者——如库内已有归档的知情同意书 V3.0，上传「知情同意书V2_…」会自动命名为 V4.0 并关联历史版本，同一文件再传一次得 V5.0；版本号识别增强：V 前缀整数也可识别（V2 → V2.0、V2.5 原样），无前缀必须带小数点（1.0 → V1.0），纯数字（日期、编号）不会误判为版本号；识别出文档类型的文件名称旁显示灰色历史图标，**点击打开「版本历史」弹窗**——同项目同中心同文档类型的全部版本（含已驳回）按版本号升序列表，归档行显示归档位置
- 「＋ 新建文件夹」（R34 起由「新建」改名）：新建空文件夹并立即行内命名，可打开后在内上传；文件夹行内重命名（铅笔图标 → 回车/失焦保存、Esc 取消），**同级已存在同名文件夹时提示「已存在同名文件夹」并保持编辑态**
- 「删除」：勾选模式（单选/全选/取消），确认后删除

### 3. REVIEW（审核）
执行人员提交的文件在此审核：
1. 点击「审核」→ 文件可直接打开预览；文件夹可打开查看内部文件后逐个审阅
2. 选择「通过」→ 归档落位：**CRA 上传时选定过目标文件夹（PM 在本中心 SITE TMF 下已建的文件夹）的文件，直接归档进该 SITE TMF 文件夹**，toast 显示「已归档至 SITE TMF / 中心 / 文件夹名」（命名与归档同源）；未选定（选的是回退标准类型）或该文件夹已被删除的文件仍按 TRANSFER 归档相同的路由落位——识别文档类型后归档至 STUDY TMF 对应「分区 / 文档类型」文件夹（未识别的进「99 待分拣」，可到 TRANSFER「待分拣」弹窗人工归位）；文件夹级联审核时子文件各自判断
3. 选择「驳回」→ 填写驳回原因，原因回传给执行人员
- 识别出文档类型的文件名称旁显示灰色历史图标，点击打开「版本历史」弹窗（同项目同中心同文档类型的全部版本，含已驳回；当前文件行高亮「当前」徽标，归档行显示归档位置）；文件夹打开后的内部文件行同样可见

### 4. STUDY TMF / SITE TMF
- 「创建目录」：弹窗按类型分两种形态——**SITE TMF 为「项目目录批量下发」表单模式（R34 起图纸版式）**，**STUDY TMF 保持目录行表格模式**：
  - **SITE 型（项目目录批量下发，R34 起按图纸版式）**：弹窗为左右双栏——左栏表单 + 右栏「目录实时预览」（上传后自动展开）。**注册表为空时弹窗整体显示引导**「请先在首页配置研究中心」（SITE 目录下发依赖首页「研究中心管理」注册表中的项目与中心）。左栏自上而下：① 顶部「项目编号」下拉（选项 = 注册表中有中心的项目去重排序，没有中心的项目不出现）+ 右上角「⊕ 研究中心（点击添加）」（未选项目时点击提示拦截；该项目中心已全部添加时再点提示拦截）；② 中部研究中心行表格（研究中心｜TMF 名称｜操作）：**R38 起——打开弹窗（页面已按项目筛选时）或切换项目编号后，自动把该项目在注册表里的全部研究中心铺成行**，TMF 名称按 `{项目编号}-TMF-{中心名}` 自动生成（可手动修改，手改后重选中心不覆盖自定义名）；行尾垃圾桶可删行，右上角「⊕ 研究中心（点击添加）」可补空行微调（中心下拉选项自动排除其他行已选的中心；未选项目时点击提示拦截，该项目中心已全部在列时再点提示拦截）；已建目录的中心照常铺出并标注「（已建目录）」+ 琥珀徽标「已建目录，将合并导入」；**仅当该项目注册表无中心（或行被手动删空）时表格显示空态**，并引导「可先到首页『研究中心管理』新增」；③ 左下「上传目录」：**一份 Excel 应用到全部研究中心行**（上传后显示文件名芯片 + 一级/二级计数，解析失败红字提示；旁边「下载模板」可下载标准模板）
  - **STUDY 型（目录行表格）**：默认紧凑单栏——工具栏（下载模板 / ＋新建加一行 / 删除）+ 目录行表格（勾选框｜项目编号纯输入｜文件夹名称（默认「{编号} STUDY TMF」随编号生成、dirty 逻辑同上）｜导入目录（「上传目录」teal 链接，上传后文件名可重传或红色「解析失败」）｜操作（「预览/收起预览」+ 删除））
- **预览**：SITE 型上传解析成功即在右栏展开实时预览（换文件立即重新解析刷新）；STUDY 型点行内「预览」展开/收起。面板含文件名、「将创建 一级×个 · 二级×个 · 三级×个」统计、目标摘要（SITE「**将下发到 N 家中心**」并**逐行列出每行最终目录名称**（= 行内 TMF 名称，随中心选择与名称编辑**实时增减**），并注明「目录无则自动新建（已建目录合并导入），同名文件夹自动跳过」；STUDY「将导入项目目录：{文件夹名称}」）+ 目录树（一级加粗、无子项标注、占满剩余高度内部滚动）；解析失败在面板内红色提示；视口 <1100px 时预览面板自动堆叠在下方。**标题栏「放大」按钮可点：切换弹窗近全屏（96vw×92vh）/ 还原**；**双栏模式下左右栏之间有拖拽分隔条（6px 热区、悬停 teal 高亮），按住左右拖动实时调整两栏宽度**（右栏最窄 320px、左栏最窄 480px，堆叠模式下不显示）；任何 ≥900px 视口下弹窗完整居中不溢出
- **确认创建**（弹窗底部右下固定，「取消」关闭弹窗）：SITE 型按 项目×研究中心行 批量执行——**校验逐级拦截**（未选项目编号 → 未添加研究中心行 → 存在未选择研究中心的行 → 存在 TMF 名称为空的行 → 未上传/解析成功前「确认创建」按钮禁用），目标目录无则自动新建（空白环境从零可用）、已建目录中心合并导入、同名文件夹自动跳过，**新建目录名 = 行内 TMF 名称**；STUDY 型校验沿用（项目编号与文件夹名称必填、至少一行已上传解析成功）；完成后 toast 汇总「目录创建完成：新建目录 × 个 · 新建文件夹 × 个 · 跳过同名 × 个」。导入的文件夹名称直接采用 Excel 原名，可正常作为 CRA 上传时的目标文件夹
  - **Excel 格式**：支持两种表头——① 标准模板「一级目录 / 二级目录 / 三级目录(可选)」；② 现有格式「序号 / 文件类别 / 名称」（文件类别=一级、名称=二级）。通则：除序号列外从左到右依次为一级/二级/三级；空白单元格向上继承（兼容合并单元格）；值为 NA / N/A / - / 空 视为无子项；整行空跳过；表头行自动定位
  - **下载模板**：工具栏「下载模板」按钮，生成标准模板 xlsx（含示例行）
  - **目录来源二选一（R39 二阶段B）**：STUDY 行「导入目录」列与 SITE 左下均由单「上传目录」扩为双来源——**「引用标准模板…」下拉**（选项=admin NAMING 页「标准目录树模板库」；选择即把模板树拷贝为本行结构，显示「标准模板：××」芯片，预览/计数/合并创建流程与 Excel 完全一致）／**「上传目录」**（现状不变）；已选后点「更换」可回到二选一；模板库为空时下拉禁用并提示去 admin 端维护；**引用即拷贝实例化——模板后续改动/删除不影响已建目录**
- 页面无任何目录时显示引导文案（点「创建目录」新建，分组上传 Excel 即自动建目录并导入）
- 点击目录行可钻取查看目录内文件（文件夹可逐级再钻取，面包屑逐级可点回退）
- **目录行内重命名**：目录列表中文件夹名称旁的铅笔图标 → 名称变为输入框（回车/失焦保存、Esc 取消）；相同类型/中心下已有同名目录时提示「已存在同名目录」并保持编辑态；改名立即持久化，钻取面包屑、钻取视图上传弹窗的「归档位置」等处同步显示新名
